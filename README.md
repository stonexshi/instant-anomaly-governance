# Instant Anomaly Governance

Instant Anomaly Governance is a pre-drift governance theory.

It defines the moment before drift becomes inherited.

An instant anomaly is not drift by itself. Drift begins only when the anomalous state is inherited into the next continuity slice and starts redirecting the valid path.

## Core Chain

Logic Slice  
→ Instant Anomaly  
→ Validity Inheritance Check  
→ Inherited or Corrected  
→ Drift or Restoration  
→ Valid-State Continuity

## Core Principle

Instant anomaly is the last observable point before drift becomes lineage.

## Simple Example

If a person is asked to buy milk, the valid path is:

go out → reach the store → locate milk → buy milk → return with milk.

When the person sees many unrelated products in the store, that moment is an instant anomaly.

If they remain focused and buy milk, the anomaly was not inherited.

If they forget the milk and start buying unrelated items, the anomaly has been inherited.

That inherited anomaly becomes drift.

## Engineering Reproduction

Each continuity slice can be represented with:

- active_objective
- valid_state
- current_context
- competing_signal
- inheritance_decision
- next_slice_state
- restoration_action
- drift_status

The key question is not only:

Did an anomaly occur?

The key question is:

Was the anomaly inherited into the next valid-state transition?

## Relation to Valid-State Continuity

Valid-State Continuity monitors whether a valid state remains valid across time, context, responsibility, and consequence transitions.

Instant Anomaly Governance acts earlier.

It detects the moment where a valid path is exposed to displacement before the displacement becomes inherited drift.

## Boundary

This theory does not claim to detect emotion, consciousness, psychology, or legal liability.

It only defines a reproducible governance distinction between:

- momentary anomaly
- inherited anomaly
- drift
- restoration
