# Definition

Instant Anomaly Governance is a pre-drift governance model.

It separates a momentary anomaly from inherited drift.

An instant anomaly occurs when a valid continuity path encounters a competing signal, context, instruction, objective, or authority pressure inside a logic slice.

The anomaly itself is not drift.

Drift begins only when the anomalous state is inherited into the next continuity slice and starts redirecting the path.

## Core distinction

Momentary anomaly does not equal drift.

Inherited anomaly becomes drift.

Corrected anomaly becomes restoration.
