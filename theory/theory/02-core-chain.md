# Core Chain

Instant Anomaly Governance follows this chain:

```text
Logic Slice
→ Instant Anomaly
→ Validity Inheritance Check
→ Inherited or Corrected
→ Drift or Restoration
→ Valid-State Continuity
```

---

# 1. Logic Slice

A Logic Slice is a bounded unit of continuity.

Inside a logic slice, the system evaluates:

- current objective
- current context
- responsibility state
- admissibility condition
- continuity direction

A logic slice is not permanent.

It represents one continuity step before the next inheritance decision occurs.

---

# 2. Instant Anomaly

An Instant Anomaly is a momentary displacement pressure inside the current logic slice.

Examples include:

- competing objectives
- distraction
- authority confusion
- conflicting instructions
- emotional interruption
- context overload
- semantic displacement
- continuity instability

An instant anomaly does not automatically become drift.

It is only a potential displacement state.

---

# 3. Validity Inheritance Check

The Validity Inheritance Check determines whether the current state should pass into the next slice.

This is the key governance boundary.

Possible outcomes include:

- inherited unchanged
- inherited with restriction
- corrected before inheritance
- blocked from inheritance
- escalated for review

The central question is:

Did the anomaly become part of the next continuity state?

---

# 4. Inherited or Corrected

If the anomaly is inherited into the next slice, continuity begins shifting away from the original valid path.

If the anomaly is corrected before inheritance, continuity remains stable.

This creates the fundamental separation between:

- inherited anomaly
- corrected anomaly

---

# 5. Drift or Restoration

Drift is inherited displacement across continuity slices.

Restoration is the prevention or correction of inherited displacement.

This means:

- not all anomalies become drift
- restoration can occur before drift forms
- governance can act before long-term instability appears

---

# 6. Valid-State Continuity

Valid-State Continuity is the long-term preservation of valid states across changing conditions.

It monitors whether:

- objectives remain aligned
- responsibility remains attributable
- admissibility remains stable
- continuity remains coherent
- consequence paths remain valid

Instant Anomaly Governance acts as a pre-drift layer inside Valid-State Continuity.

It detects the final observable moment before displacement becomes inherited lineage.

---

# Core Principle

Instant anomaly is the last observable point before drift becomes lineage.
